# The Easy Way to Quit YouTube Addiction

An open-source guide to breaking free from Youtube Addiction.

Read the chapters in order, and do not force yourself to quit watching YouTube until you finish the book.

## Acknowledgments

This book is an independent adaptation of psychological concepts originally developed by others. Full credit for the underlying methodology and psychological framework goes to:

- Allen Carr for creating the original *Easyway* method.
- Hackauthor and the contributors behind the [EasyPeasy project](https://easypeasymethod.org/) for adapting the framework to modern behavioral dependencies.
